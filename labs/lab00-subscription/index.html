    Lab 00 — 내 실습 환경 확인하기

    이 실습에서 하는 것

    강사가 배부한 계정으로 로그인해서, 내가 4일 동안 쓸 자리를 확인합니다. 구독·리소스 그룹·리전을 기록해 두는 것이 목표입니다. 뒤 랩에서 계속 씁니다.

    선행 없음 · 예상 시간 33분 · 비용 0원

    0. 이 과정의 계정 방식 (3분)

    구독은 강사 것, 작업 공간은 내 것입니다

    여러분은 강사의 교육용 구독 안에 있는 내 전용 리소스 그룹에서 작업합니다. 가입 절차도, 신용카드도, 크레딧 관리도 없습니다.

    강사의 교육용 구독
├─ rg-ai901-01   ← 1번 수강생의 자리 (여기 안에서만 작업)
├─ rg-ai901-02   ← 2번 수강생의 자리
└─ ...
    강사가 미리 만들어 둔 것 내가 수업 중에 만드는 것
    구독 ✅ —
    예산 알림 ✅ —
    내 계정 ai901-<번호> ✅ —
    내 리소스 그룹 rg-ai901-<번호> ✅ —
    Foundry 리소스·프로젝트 — ✅ Lab 01
    모델 배포 — ✅ Lab 02
    에이전트 — ✅ Lab 08

    리소스 그룹까지는 받아서 시작하고, 그 안의 모든 것은 직접 만듭니다. 리소스를 만드는 절차 자체가 시험 범위라서 그렇습니다.

    신용카드를 요구하는 화면이 나오면 멈추세요

    이 과정에서는 어떤 화면에서도 카드 번호를 넣지 않습니다. 카드를 요구하는 화면이 나왔다면 잘못된 가입 흐름으로 들어간 것입니다. 강사를 부르세요.

    1. 로그인 (10분)

    배부받은 종이(또는 메시지)에 이렇게 적혀 있습니다.

    번호        01
계정        ai901-01@<테넌트도메인>
초기 비밀번호  <배부된 값>
리소스 그룹   rg-ai901-01

    1. 브라우저에서 portal.azure.com 에 접속합니다.

      이미 다른 Microsoft 계정으로 로그인돼 있다면

      시크릿 창(InPrivate) 을 열어서 접속하세요. 계정이 섞이면 4일 내내 헷갈립니다. 크롬은 Ctrl+Shift+N, 엣지는 Ctrl+Shift+N 입니다. (macOS는 Cmd+Shift+N)

    2. 배부받은 계정과 초기 비밀번호로 로그인합니다.

    3. 배부받은 비밀번호로 바로 들어갑니다. 변경을 요구하지 않습니다.

      바꾸고 싶으면 바꿔도 됩니다 (권장)

      배부된 비밀번호는 번호만 다른 공통 패턴입니다. 남이 추측할 수 있습니다. 우상단 프로필 → 내 계정 보기 → 암호 에서 바꿀 수 있습니다.

      바꿨으면 반드시 메모하세요. 잊어버리면 강사가 초기화해 드려야 합니다 (2~3분).

    4. 추가 보안 정보(MFA) 등록을 요구할 수 있습니다. 화면 안내를 따르세요.

      휴대폰 인증을 요구하면 해도 되나요

      네, 본인 휴대폰으로 진행하세요. 테넌트 정책에 따라 요구될 수 있습니다. 이 단계에서 막히면 바로 손을 드세요 — 여기서 늦어지면 1일차 전체가 밀립니다.

    2. 내 자리 확인하기 (7분)

    ① 구독이 보이는가

    포털 상단 검색창에 구독 을 입력하고 들어갑니다. 구독이 하나 보이면 정상입니다. 이름과 구독 ID를 확인하세요.

    ② 내 리소스 그룹이 보이는가

    검색창에 리소스 그룹 을 입력하고 들어갑니다.

    내 번호의 그룹 하나만 보여야 정상입니다

    rg-ai901-<내 번호> 가 보이면 됩니다. 다른 사람의 그룹은 보이지 않습니다. 권한이 내 그룹에만 주어졌기 때문입니다.

    여러 개가 보이거나 아무것도 안 보이면 손을 드세요. 권한 설정 문제입니다.

    ③ 리전 확인 — 전원 East US 2

    Lab 01부터 리소스를 만들 때 고를 리전입니다. 수강생 전원이 같은 리전을 씁니다.

    East US 가 아니라 East US 2 입니다

    목록에서 바로 위아래로 붙어 있어 가장 많이 틀리는 지점입니다. 숫자 2가 붙은 쪽을 고르세요. 한국어 포털에서는 미국 동부 2.

    이 리전이어야 4일 과정에 필요한 모델이 전부 보입니다.

    리소스 그룹의 “위치”와 달라도 정상입니다

    그룹을 클릭하면 위치(Location) 가 보입니다. 위 표와 달라도 문제가 아닙니다.

    그룹의 위치는 그룹 정보가 저장되는 곳일 뿐입니다. 리소스를 어느 리전에 만들지는 Lab 01에서 내가 고릅니다. 위 표를 따르세요.

    3. 내 환경 기록표 (5분)

    이 표를 꼭 적어 두세요

    4일 동안 계속 돌아와서 보게 됩니다. 노트에 적거나, 메모장 파일로 만들어 두세요. 외우려 하지 마세요.

    항목 내 값 어디서 확인 처음 쓰는 곳
    내 번호 ____ 배부받은 종이 —
    계정 ai901-__@________ 배부받은 종이 Lab 00
    리소스 그룹 rg-ai901-__ 포털 → 리소스 그룹 Lab 01
    리전 ____________ 번호별 표 (위 ③) Lab 01
    Foundry 리소스 이름 (Lab 01에서 정함) — Lab 01
    프로젝트 이름 (Lab 01에서 정함) — Lab 01
    모델 배포 이름 (Lab 02에서 정함) — Lab 02
    엔드포인트 (Lab 02에서 조립) — Lab 02

    아래 네 줄은 지금 비어 있는 게 정상입니다. 해당 랩에서 채웁니다.

    4. Python 설치 확인 (3분)

    오늘 오후 Lab 02 에서 바로 씁니다 — 지금 확인하세요

    여기서 없는 걸 발견해야 점심시간에 설치할 수 있습니다. 오후에 발견하면 혼자 20분 뒤처집니다.

    터미널(Windows 는 PowerShell)을 열고:

    python --version

    python3 --version

    Python 3.10 이상이 나오면 통과입니다.

    “명령을 찾을 수 없습니다” / 버전이 3.10 미만입니다

    지금 손을 드세요. 설치는 쉽지만 10~20분 걸립니다.

    설치 절차는 수업 전 설치 에 화면 그림까지 정리돼 있습니다. 그 페이지를 열어서 따라 하시면 됩니다.

    가장 많이 걸리는 두 지점만 미리 알려드립니다.

    • 설치 첫 화면의 「Add python.exe to PATH」 체크 ← 기본값이 꺼져 있습니다
    • 설치 뒤 터미널을 닫고 새로 여세요
    • python 이 아니라 python3 입니다

    설치가 오래 걸리면 점심시간에 이어서

    Lab 01 은 포털에서만 하므로 Python 없이도 진행됩니다. Lab 02 시작 전까지만 되면 됩니다.

    끝까지 안 되면 — 브라우저로 할 수 있습니다

    Foundry 포털에 웹용 VS Code 가 있습니다. Python 설치 없이 브라우저에서 바로 코드를 돌릴 수 있어요. 방법은 Lab 02 에 있습니다.

    수업은 따라갈 수 있습니다. 혼자 설치하다 뒤처지지 마세요.

    5. 권한의 경계 확인하기 (5분)

    일부러 실패해 보는 단계입니다

    내 권한이 어디까지인지 직접 확인해 둡니다. 이걸 지금 해보면 Lab 01에서 당황하지 않습니다.

    1. 포털 검색창 → 리소스 그룹 → + 만들기
    2. 아무 이름이나 넣고 검토 + 만들기 를 눌러 봅니다

    실패하는 것이 정상입니다

    권한 오류(AuthorizationFailed 또는 "권한이 없습니다")가 나옵니다.

    왜 그런가 — 여러분의 권한은 rg-ai901-<번호> 그룹 안에서만 유효합니다. 구독 전체에 대한 권한은 없습니다. 의도된 설계입니다.

    할 수 있는 것 할 수 없는 것
    내 그룹 안에 리소스 만들기·지우기 새 리소스 그룹 만들기
    내 그룹 안의 키·엔드포인트 보기 다른 사람 그룹 들여다보기
    내 그룹 안에서 모델 배포·에이전트 생성 구독 설정·예산 변경

    내 리소스 그룹 자체는 지우지 마세요

    그룹을 지우면 거기에 걸려 있던 내 권한도 함께 사라집니다. 강사가 다시 만들어 줘야 하고, 그동안 실습을 못 합니다.

    4일차 Lab 16에서는 그룹 안의 리소스만 지웁니다. 그룹은 남겨 둡니다.

    6. 비용은 어떻게 보나 (선택 · 3분)

    비용은 강사가 구독 단위로 보고 있습니다. 예산 알림도 강사 쪽에 걸려 있습니다. 여러분이 따로 걸 것은 없습니다.

    그럼 내가 얼마 쓰는지는 어떻게 아나요

    포털 검색창 → 비용 관리 → 비용 분석 에서 리소스 그룹 으로 필터하면 내 그룹의 사용액을 볼 수 있습니다 (권한에 따라 안 보일 수도 있습니다).

    4일 실습 전체가 1인 몇십 센트 수준으로 설계돼 있습니다. 다만 이미지 생성 모델 배포를 방치하면 단가가 높으니, Lab 14에서 꼭 지우세요.

    7. ✅ 체크포인트

    여기까지 됐으면 통과입니다

    • [ ] 배부받은 계정으로 포털에 로그인했다
    • [ ] 지금 쓰는 비밀번호를 기억하고 있다 (바꿨다면 메모했다)
    • [ ] 구독 이 하나 보인다
    • [ ] rg-ai901-<내 번호> 그룹이 보인다 (내 것 하나만)
    • [ ] 리전이 East US 2 라는 걸 확인했다 (East US 아님)
    • [ ] 환경 기록표 의 윗줄 네 개를 적었다
    • [ ] python --version 이 3.10 이상이다 ← 안 되면 점심에 설치
    • [ ] 새 리소스 그룹 만들기가 실패하는 것을 확인했다

    다 체크됐으면 손을 들어 주세요. 전원이 끝나야 Lab 01로 넘어갑니다.

    🔧 안 될 때

    로그인이 안 됩니다 (비밀번호가 틀리다고 나옵니다)
    1. 배부받은 비밀번호를 직접 타이핑 해 보세요 (복사하면 공백이 섞입니다)
    2. 대소문자를 확인하세요
    3. 계정 주소의 도메인 부분까지 정확히 넣었는지 확인하세요
    4. 그래도 안 되면 손을 드세요. 강사가 비밀번호를 초기화합니다 (2~3분)
    “조직에서 이 계정을 관리합니다” 같은 안내가 나옵니다

    정상입니다. 교육용 테넌트의 계정이라서 그렇습니다. 계속 진행하세요.

    MFA(추가 보안 정보) 등록에서 막혔습니다
    • 휴대폰으로 SMS 또는 Authenticator 앱 등록을 진행하세요
    • 앱 설치가 오래 걸리면 전화(SMS) 방식을 고르세요
    • 그래도 막히면 손을 드세요. 정책 예외를 적용할 수 있습니다
    리소스 그룹 목록이 비어 있습니다
    1. 우상단 프로필을 눌러 배부받은 계정으로 로그인됐는지 확인하세요 (개인 계정으로 들어가 있는 경우가 가장 많습니다)
    2. 우상단 디렉터리 전환에서 교육용 디렉터리가 선택돼 있는지 확인하세요
    3. 브라우저를 시크릿 창으로 다시 열어 보세요
    4. 그래도 비어 있으면 손을 드세요 — 권한 부여가 누락된 것입니다
    다른 사람의 리소스 그룹도 보입니다

    권한이 너무 넓게 들어간 것입니다. 손을 드세요. 다른 사람 그룹에는 아무것도 하지 마세요.

    포털이 영어로 나옵니다

    오른쪽 위 ⚙️(설정) → 언어 및 지역 → 한국어 로 바꿀 수 있습니다. 이 가이드는 한국어 메뉴 기준이지만, 영어로 쓰실 경우 괄호 안 영어 이름을 참고하세요.

    💡 각자 구독으로 진행하는 경우

    이 과정의 기본은 강사 배부 계정입니다

    사정상 본인 구독으로 진행하는 경우에만 아래를 참고하세요. 강사가 별도로 안내하지 않았다면 해당되지 않습니다.

    1. Azure for Students (azure.microsoft.com/free/students) — 학교 이메일로 가입, 카드 불필요, $100 / 12개월. 학교 도메인이 Microsoft 학술 인증 목록에 없으면 실패할 수 있습니다.
    2. 가입 후 비용 관리 → 예산 에서 본인 구독에 $20 예산 알림을 직접 거세요.
    3. 이후 모든 랩에서 rg-ai901-<번호> 는 본인이 만든 리소스 그룹 이름으로 바꿔 읽으세요. 본인 구독에서는 새 리소스 그룹을 직접 만들 수 있습니다.
