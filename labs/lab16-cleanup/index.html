    Lab 16 — 리소스 정리

    이 실습에서 하는 것

    4일 동안 내 리소스 그룹 안에 만든 것들을 지웁니다. 그룹 자체는 남겨 둡니다 — 이유는 아래에 있습니다.

    선행 전체 랩 완료 · 예상 시간 12분 · 비용 0원 (오히려 막는 작업)

    0. 무엇이 돈을 쓰고 있나 (2분)

    만든 것 켜두면 과금되나
    Foundry 리소스 · 프로젝트 ❌ 그 자체로는 아님
    모델 배포 (종량제) ❌ 호출할 때만
    에이전트 · 업로드한 파일 저장 용량만 (아주 적음)
    이미지 생성 모델 배포 ⚠️ 단가 높음 — Lab 14에서 이미 삭제
    Speech 리소스 ❌ 쓴 만큼만
    「검색 서비스」 Azure AI Search ⚠️ 켜져 있는 시간만큼 — 표준 계층 시간당 약 $0.33

    그럼 안 지워도 되는 거 아닌가요

    종량제라 당장 큰돈은 안 나갑니다. 그런데 잊어버리는 게 문제입니다.

    • 나중에 실수로 호출하는 코드를 돌리면 계속 빠져나갑니다
    • 확보형으로 바뀌거나 비싼 모델을 배포해 두면 모르는 새 소진됩니다
    • 교육용 구독은 다음 기수도 씁니다. 남겨두면 다음 사람 환경이 더러워집니다

    쓰지 않는 건 지운다 — 클라우드의 기본 습관입니다.

    1. 왜 그룹은 남기나 (2분)

    리소스 그룹 자체를 지우면 안 됩니다

    여러분의 권한은 rg-ai901-<번호> 그룹에 걸려 있습니다. 그룹을 지우면 권한도 함께 사라져서 아무것도 못 하게 됩니다.

    rg-ai901-01  ← 권한이 여기 붙어 있다
  ├─ ai901-01-xxx     (Foundry 리소스)   ← 이것들만 지운다
  └─ speech-ai901-01  (Speech 리소스)    ← 이것들만 지운다

    그룹 안의 리소스만 지우세요. 빈 그룹은 과금되지 않습니다. 그룹은 수업 뒤 강사가 일괄 정리합니다.

    ★ 시험과 이어지는 지점

    "리소스 그룹을 삭제하면 어떻게 되는가?" → 안에 든 리소스가 전부 함께 삭제된다 이건 사실입니다. 다만 그룹에 걸린 역할 할당도 함께 사라진다는 점이 실무에서 자주 사고를 냅니다. 오늘 그걸 피하는 방식으로 정리합니다.

    2. 내 그룹 안의 리소스 지우기 (5분)

    1. portal.azure.com → 검색창에 리소스 그룹
    2. rg-ai901-<내 번호> 클릭
    3. 안에 무엇이 있는지 한 번 훑어보세요 (4일 동안 만든 것들입니다)
    4. 목록 맨 위의 체크박스를 눌러 전체 선택합니다
    5. 상단 삭제 를 누릅니다
    6. 확인 입력을 요구하면 화면이 지시하는 문자열(보통 delete)을 입력합니다
    7. 삭제

    “프로젝트가 있어서 못 지운다”고 나오면 — 삭제에는 순서가 있습니다

    Foundry 리소스는 안에 프로젝트가 남아 있으면 지워지지 않습니다. 전체 선택으로 한 번에 지우려 할 때 이 오류가 날 수 있습니다.

    CannotDeleteResource — Cannot delete resource while nested resources exist

    이때는 안쪽부터 바깥쪽으로 하나씩 지우세요.

    순서 지울 것
    1 모델 배포 · 에이전트 — 프로젝트 안의 것
    2 프로젝트 proj-ai901
    3 Foundry 리소스 ai901-<번호>-<이니셜>

    ★ 시험 포인트

    삭제는 안쪽 → 바깥쪽. Lab 01에서 리소스가 바깥 그릇, 프로젝트가 그 안의 작업 공간이었던 그 구조가 지울 때 역순으로 나타납니다. 바깥 그릇을 먼저 지우려 하면 막힙니다.

    삭제는 되돌릴 수 없습니다

    에이전트, 업로드한 규정 문서, 모델 배포가 전부 사라집니다. 남기고 싶은 게 있으면 먼저 내려받으세요.

    로컬 폴더(ai901/)의 코드는 그대로 남습니다. 지워지는 건 Azure 쪽뿐입니다.

    삭제에 2~5분 걸립니다.

    그룹 삭제 버튼을 누르지 않도록 주의하세요

    화면 상단에는 리소스 그룹 삭제 버튼도 함께 있습니다. 우리가 누를 것은 리소스를 선택한 뒤의 삭제 입니다.

    3. 확인 (3분)

    ① 그룹이 비었는지

    rg-ai901-<번호> 안의 목록이 비어 있으면 완료입니다. 그룹 이름 자체는 남아 있는 게 정상입니다.

    ② 다른 데 남은 게 없는지

    포털 검색창에 모든 리소스 를 입력해서 목록을 봅니다. 내 권한 범위에서 보이는 리소스가 없으면 깨끗하게 정리된 것입니다.

    ★ 「검색 서비스」가 남아 있는지 꼭 보세요

    이 과정에서는 Azure AI Search 를 쓰지 않습니다. 포털에서 리소스를 찾다 실수로 만든 사람이 있을 수 있는데, 이것만은 안 써도 시간당 과금됩니다.

    az resource list --resource-type Microsoft.Search/searchServices -o table

    목록에 뭔가 나오면 지우세요. 다른 리소스와 달리 남겨두면 계속 빠져나갑니다.

    Lab 11의 Speech 리소스는요

    Lab 11에서도 같은 그룹 안에 만들었으니 2절에서 함께 지워졌습니다. 혹시 목록에 남아 있으면 지우세요.

    ③ 사용액 (선택)

    비용 관리 → 비용 분석 에서 리소스 그룹 으로 필터해 보세요. 권한에 따라 안 보일 수 있습니다. 안 보이면 넘어가세요 — 구독 전체는 강사가 확인합니다.

    4. 로컬 정리 (2분)

    Azure 쪽은 지웠지만 노트북의 .env 에는 키가 남아 있습니다.

    .env 는 비밀번호 파일입니다

    • 지운 리소스의 키라 이제 쓸모없지만, 습관을 들이세요
    • 절대 GitHub에 올리지 마세요. .gitignore 에 .env 를 넣는 게 기본입니다
    # .gitignore 를 만든다면
echo ".env" >> .gitignore
echo ".venv/" >> .gitignore

    코드 파일은 지우지 마세요. 나중에 본인 구독을 만들면 그대로 쓸 수 있습니다.

    집에서 이어서 하고 싶다면

    requirements.txt 와 코드 파일을 그대로 두고, 본인 구독(Azure for Students 등)에서 Lab 01·02를 다시 하면 됩니다. .env 의 세 값만 새로 채우면 나머지 코드는 전부 그대로 돕니다.

    5. ✅ 체크포인트

    여기까지 됐으면 과정 완료입니다

    • [ ] rg-ai901-<번호> 안의 리소스가 비었다
    • [ ] 리소스 그룹 자체는 남아 있다 ← 지우지 않았는지 확인
    • [ ] 모든 리소스 목록에 남은 게 없다
    • [ ] 이미지 생성 모델 배포가 남아 있지 않다 (Lab 14에서 삭제)
    • [ ] 로컬 .env 의 성격을 이해했다

    전원이 확인되어야 끝납니다. 삭제가 진행 중이면 "삭제 중" 상태라도 괜찮습니다.

    🔧 안 될 때

    삭제가 실패합니다
    • 다른 리소스가 참조 중일 수 있습니다. 2~3분 뒤 다시 시도하세요
    • 2절의 안쪽 → 바깥쪽 순서대로 하나씩 지워 보세요 (배포 → 프로젝트 → 리소스)
    • 그래도 안 되면 손을 드세요. 강사가 정리 스크립트로 일괄 처리합니다
    삭제 중에서 멈춰 있습니다

    5~10분 걸릴 수 있습니다. 새로고침해 보세요. 오래 걸려도 백그라운드에서 진행되니 퇴실하셔도 됩니다.

    실수로 리소스 그룹을 지웠습니다

    괜찮습니다. 지금은 마지막 랩이라 실습에 지장이 없습니다. 강사에게 알려만 주세요. 다음 기수 준비 때 다시 만듭니다.

    (수업 중이었다면 권한이 사라져서 실습이 중단됐을 겁니다. 그래서 2절에서 주의를 드렸습니다.)

    리소스 그룹이 보이지 않습니다

    로그인 계정을 확인하세요 (우상단 프로필). 배부받은 계정이 아니면 내 그룹이 보이지 않습니다.

    🎓 4일 과정을 마치며

    4일 동안 만든 것들입니다.

    일차 만든 것
    1일차 실습 환경 · Foundry 리소스·프로젝트 · 첫 호출
    2일차 모델 배포 · 토큰 이해 · 멀티턴 챗봇 · 근거 기반 답변
    3일차 에이전트(지식 연결) · 코드 호출 · 텍스트 분석 · 음성
    4일차 멀티모달 이미지 · 이미지 생성 · 문서 필드 추출

    로컬 ai901/ 폴더에 코드 12개가 남아 있습니다. 다시 환경을 만들면 그대로 돌아갑니다. 포트폴리오로 쓰셔도 좋습니다.

    마지막으로

    시험은 목표가 아니라 확인입니다. 여러분은 이미 만들 줄 아는 상태입니다. 그 상태를 점수로 증명하는 절차일 뿐이에요.

    연습문제에서 정답률 80% 가 안정적으로 나오면 신청하세요. 합격 소식 기다리겠습니다.

    점수에 대해 하나만

    AI-900/AI-901의 합격선은 1000점 만점에 700점이지만, 이건 문항 수가 아니라 척도 점수(scaled score) 입니다. "40문제 중 28개"처럼 환산되지 않습니다. 그래서 연습문제에서는 자체 정답률 80% 를 기준으로 삼으세요.
