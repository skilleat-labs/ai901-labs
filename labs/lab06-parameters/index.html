    Lab 06 — 매개변수 실험

    이 실습에서 하는 것

    같은 질문인데 답이 달라지게, 또는 항상 같게 만듭니다. 온도(temperature) 와 최대 토큰을 직접 돌려 봅니다.

    선행 Lab 05 완료 · 예상 시간 20분 · 비용 약 $0.02 미만

    1. 플레이그라운드에서 감 잡기 (7분)

    코드보다 화면이 빠릅니다.

    1. ai.azure.com → 내 프로젝트 → 플레이그라운드
    2. 모델을 gpt-5.4-mini 로 선택
    3. 오른쪽(또는 설정 아이콘)에서 온도 슬라이더를 찾습니다

    같은 질문을 온도만 바꿔서 3번

    프롬프트: "우리 동네 카페 이름을 하나 지어줘."

    온도 1차 2차 3차
    0
    0.7
    1.5

    무엇이 보이나요

    • 온도 0 — 세 번 다 거의 같은 답
    • 온도 1.5 — 매번 다르고, 가끔 엉뚱함

    2. 코드에서 해보기 (8분)

    params.py 를 만듭니다.

    import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI(
    base_url=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("API_KEY"))
MODEL = os.getenv("MODEL_DEPLOYMENT_NAME")

for t in [0, 0.7, 1.5]:
    print(f"\n=== 온도 {t} ===")
    for i in range(2):
        r = client.responses.create(
            model=MODEL,
            input="우리 동네 카페 이름을 하나 지어줘. 이름만 답해.",
            temperature=t)
        print(f"  {i+1}회차: {r.output_text.strip()}")

    python params.py

    3. 최대 토큰 (5분)

    답의 길이 상한입니다. 비용을 통제하는 가장 직접적인 방법입니다.

    r = client.responses.create(
    model=MODEL,
    input="인공지능의 역사를 설명해줘.",
    max_output_tokens=60)
print(r.output_text)

    말이 중간에 끊깁니다

    한도에 걸리면 문장이 끊긴 채로 돌아옵니다. 예쁘게 요약해 주지 않습니다.

    짧게 받고 싶으면 프롬프트로도 같이 지시하세요. "3문장 이내로 답해." + max_output_tokens 를 함께 쓰는 게 안전합니다.

    4. ✅ 체크포인트

    여기까지 됐으면 통과입니다

    • [ ] 온도 0에서 답이 거의 일정한 것을 확인했다
    • [ ] 온도 1.5에서 답이 매번 달라지는 것을 확인했다
    • [ ] max_output_tokens 로 답이 중간에 끊기는 것을 확인했다
    • [ ] 각 값을 언제 쓸지 말할 수 있다

    5. 언제 무엇을 쓰나

    상황 온도 왜
    문서 요약 · 분류 · 데이터 추출 낮게 (0~0.3) 같은 입력엔 같은 답이 나와야 합니다
    고객 응대 챗봇 중간 (0.5~0.8) 자연스럽되 튀지 않게
    카피라이팅 · 아이디어 높게 (1.0~1.5) 다양한 안이 필요합니다

    ★ 시험에 이렇게 나옵니다

    "같은 입력에 대해 항상 일관된 결과가 필요하다. 어떻게 설정하는가?"

    → 온도를 낮춘다(0에 가깝게).

    "응답 길이를 제한하려면?"

    → 최대 토큰(max output tokens).

    🔧 안 될 때

    temperature 를 넣으니 오류가 납니다

    모델에 따라 지원하지 않는 매개변수가 있습니다. 오류 메시지에 지원되지 않는다고 나오면 그 모델에서는 플레이그라운드로만 확인하고 넘어가세요.

    온도를 0으로 해도 답이 조금씩 다릅니다

    정상입니다. 온도 0이 "완전히 똑같음"을 보장하지는 않습니다. "훨씬 일관되게"가 맞는 표현입니다.

    max_output_tokens 가 안 먹습니다

    SDK 버전에 따라 이름이 다를 수 있습니다. 오류 메시지에 제안된 이름을 쓰세요. 플레이그라운드의 슬라이더로 확인해도 됩니다.
