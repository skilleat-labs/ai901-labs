    Lab 12 — Voice Live 실시간 음성 (강사 데모)

    이 랩은 보는 실습입니다

    직접 실행하지 마세요. 강사 화면을 보면서 관찰 포인트만 기록합니다.

    선행 Lab 11 완료 · 예상 시간 15분 · 수강생 비용 0원

    0. 왜 직접 안 하나요

    이유가 두 가지입니다.

    ① 할당량이 아주 작습니다. 실시간 모델은 구독 전체 할당량이 10 안팎이라 32명이 동시에 세션을 열 수 없습니다.

    ② 주고받는 오디오가 곧 비용입니다. 대화가 길어지면 이 과정에서 가장 비싼 구간이 됩니다.

    과금 단위가 서비스마다 다릅니다

    과금 기준
    모델 호출 (Lab 02~07) 토큰 (입력 + 출력)
    Lab 11 STT · TTS 처리 분량 — 합성은 문자 수, 인식은 오디오 길이 (월 무료 한도 있음)
    Voice Live 모델 등급(Pro · Standard · Lite) 에 따른 오디오·텍스트 토큰

    흔한 오해 — “연결을 열어둔 시간”이 아닙니다

    연결만 열어두고 아무것도 주고받지 않으면 거의 과금되지 않습니다. 주고받은 오디오와 텍스트가 토큰으로 환산되어 과금됩니다.

    오디오는 길이로 토큰을 환산합니다. Azure OpenAI 모델 기준으로 입력 초당 약 10토큰, 출력 초당 약 20토큰입니다. 캐시된 입력도 과금됩니다.

    ★ 시험 포인트

    "실시간 음성의 비용 구조는?" → 고른 모델의 등급과 주고받은 오디오·텍스트 토큰. 등급은 사용자가 직접 고르는 게 아니라 모델을 고르면 따라옵니다.

    1. 무엇이 다른가 (5분 · 설명)

    지금까지는 이렇게 순서대로 했습니다.

    [음성] → STT → [글자] → 모델 → [글자] → TTS → [음성]

    Voice Live는 이 과정을 하나의 연결 안에서 동시에 처리합니다.

    [음성] ←─────── 실시간 양방향 연결 ───────→ [음성]
    파이프라인 (Lab 11) Voice Live
    단계 STT → 모델 → TTS (각각 호출) 하나의 연결
    지연 단계마다 쌓임 훨씬 짧음
    끼어들기 어려움 가능 (말 중간에 끊을 수 있음)
    비용 처리 분량 기준 모델 등급 + 오디오·텍스트 토큰

    그럼 항상 Voice Live를 쓰면 되나요

    아닙니다. 실시간 대화가 필요할 때만 씁니다. 녹음 파일을 나중에 받아적는 일이라면 파이프라인이 훨씬 쌉니다.

    2. 강사 데모 — 관찰 포인트 (8분)

    강사 화면을 보면서 세 가지만 확인하세요.

    관찰 기록

    ① 지연 시간 말이 끝나고 답이 시작되기까지 몇 초쯤 걸리나요? Lab 11과 비교하면?

    → 기록: ________________

    ② 끼어들기 AI가 말하는 중간에 사람이 말을 걸면 어떻게 되나요?

    → 기록: ________________

    ③ 연결 상태 표시 화면 어디에서 "연결 중"을 알 수 있나요? 이게 왜 중요한가요?

    → 기록: ________________

    3. 언제 쓰는가 (2분)

    상황 선택
    콜센터 실시간 응대 Voice Live
    음성 비서 · 실시간 통역 Voice Live
    녹음된 회의록 받아쓰기 파이프라인 (STT)
    안내 방송 음성 생성 파이프라인 (TTS)
    상담 녹취 1,000건 분석 일괄 처리(batch)

    ★ 시험 함정 — 긴 녹음에 실시간을 고르지 마세요

    "지난 6개월 상담 녹취를 분석한다" 에 Voice Live나 recognize_once 를 고르면 오답입니다. → 일괄 처리(batch transcription) 입니다.

    4. ✅ 체크포인트

    여기까지 됐으면 3일차 완료입니다

    • [ ] 파이프라인과 Voice Live의 구조 차이를 그릴 수 있다
    • [ ] Voice Live의 과금이 모델 등급과 오디오·텍스트 토큰 기준이라는 걸 안다
    • [ ] 실시간 / 파이프라인 / 일괄 처리를 상황에 맞게 고를 수 있다
    • [ ] 관찰 포인트 세 가지를 기록했다
