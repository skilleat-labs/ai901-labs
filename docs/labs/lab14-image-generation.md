## 2. 코드로 생성하기 (8분)

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI(
    base_url=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("API_KEY"))

response = client.responses.create(
    model="여기에_이미지모델_배포이름",
    input="눈 내리는 한옥 마을의 저녁 풍경. 따뜻한 창문 불빛.")

print(response)
```

```bash
python generate_image.py
```

!!! note "★ 시험 포인트 — 생성도 Responses API 입니다"
    "프로그래밍 방식으로 이미지를 생성하려면?"
    → **배포된 이미지 모델에 Responses API로 텍스트 프롬프트를 전송**합니다.

    "플레이그라운드에 업로드한다" 같은 선택지는 오답입니다.

### 결과 받기

응답 구조는 모델마다 다릅니다. `print(response)` 로 전체를 찍어 보고,
이미지 데이터(URL 또는 base64)가 어디 들어 있는지 찾아보세요.

!!! tip "포털 플레이그라운드가 더 편합니다"
    코드에서 응답 구조 파싱이 번거로우면, **플레이그라운드에서 한 장 생성**해 보는 것으로
    대체해도 됩니다. 시험이 묻는 건 "어떤 API를 쓰는가"이지 파싱 코드가 아닙니다.

## 3. 비디오 생성은 왜 다른가 (3분)

Sora 같은 **비디오 생성**은 호출 방식이 다릅니다.

| | 이미지 생성 | 비디오 생성 |
|---|---|---|
| 처리 | 바로 결과 | **비동기** — 작업을 제출하고 기다림 |
| 이유 | 몇 초 | **리소스를 많이 쓰고 오래 걸림** |

!!! note "★ 시험에 나옵니다"
    "Sora 비디오 생성이 비동기인 이유는?"
    → **리소스를 많이 사용하고 완료에 시간이 걸리기 때문**

    "사용자 상호작용이 필요해서"는 오답입니다.

**비디오는 실습하지 않습니다.** 단가가 매우 높습니다.
