# Lab 01 — Foundry 리소스와 프로젝트 만들기

!!! info "이 실습에서 하는 것"
    AI를 담을 **그릇 두 개**를 만듭니다. 바깥 그릇이 **리소스**, 그 안의 작업 공간이 **프로젝트**입니다.

**선행** [Lab 00](lab00-subscription.md) 완료 · **예상 시간** 40분 · **비용** 0원 (만들기만 해서는 과금되지 않습니다)

!!! info "내 자리에서 작업합니다"
    모든 리소스는 **`rg-ai901-<내 번호>`** 안에 만듭니다.
    그룹은 Lab 00에서 이미 받았으니 **새로 만들지 않습니다.**

---

## 0. 먼저 이해하고 가기

강의에서 들은 내용을 한 줄로 정리하면 이렇습니다.

| | 무엇인가 | 여기에 붙는 것 |
|---|---|---|
| **리소스** (Resource) | 결제·지역·할당량의 단위 | 구독 · 리전 · 요금 · TPM |
| **프로젝트** (Project) | 실제로 일하는 작업 공간 | 모델 배포 · 에이전트 · 도구 |

개념상 순서는 **리소스 → 프로젝트**입니다. 프로젝트는 리소스 **안에** 들어갑니다.

!!! tip "다만 포털에서는 둘을 한 번에 만듭니다"
    Azure 포털의 Foundry 만들기 화면에서 **리소스 이름과 프로젝트 이름을 같이** 입력합니다.
    따로 두 번 만들러 가지 않습니다. **개념은 둘, 작업은 한 번**입니다.

!!! question "왜 둘로 나눠져 있나요"
    팀이 여럿일 때 **결제는 한 군데서 하고, 작업 공간은 나누기** 위해서입니다.
    시험에도 이 구분이 그대로 나옵니다. "지역을 정하는 건 어디인가?" → **리소스**입니다.

## 1. 리전(지역) 정하기 (7분)

리전은 **나중에 바꿀 수 없습니다.** 리소스를 다시 만들어야 합니다. 그래서 먼저 정합니다.

### 무엇을 보고 정하나

| 기준 | 설명 |
|---|---|
| **모델 가용성** | `gpt-image` · `Sora` 같은 모델은 **일부 리전에만** 있습니다 |
| 단가 | 같은 모델도 리전마다 가격이 다를 수 있습니다 |
| 지연 시간 | 가까울수록 응답이 빠릅니다 |
| 데이터 위치 | 규제 산업에서는 데이터가 어디 있는지가 중요합니다 |

### 이번 수업에서는 — 번호에 따라 두 리전으로 나눕니다

!!! danger "내 번호의 리전만 쓰세요"
    | 내 번호 | 쓸 리전 | 포털에서 고를 항목 |
    |---|---|---|
    | **01 ~ 20** | **East US** | `East US` · 미국 동부 |
    | **21 ~ 40** | **West US 3** | `West US 3` · 미국 서부 3 |

    옆자리와 리전이 다를 수 있습니다. **정상입니다.**
    임의로 다른 리전을 고르면 뒤 랩에서 모델이 안 보이거나 할당량이 부족합니다.

    !!! danger "`East US` 와 `East US 2` 는 다른 리전입니다"
        01~20번은 **숫자가 없는 `East US`** 입니다. 목록에서 바로 아래위에 붙어 있어
        가장 많이 틀리는 지점입니다. 한국어 포털에서는 **미국 동부** (미국 동부 2 아님).

!!! question "왜 한 리전으로 안 하나요 — 이게 바로 할당량입니다"
    Azure는 **리전마다** 만들 수 있는 Foundry 리소스 수에 상한이 있습니다.
    이 구독은 **리전당 30개**입니다. 40명이 한 리전에 몰리면 **31번째부터 실패**합니다.

    그래서 두 리전으로 나눴습니다. 두 리전 모두 4일 과정에 필요한 모델과 서비스를
    전부 지원하는 것을 미리 확인해 두었습니다.

    **★ 시험 포인트** — 할당량(Quota)은 **구독 × 리전 × 모델** 단위로 걸립니다.
    "리소스를 더 만들 수 없다"면 → 다른 리전을 쓰거나 **할당량 증설을 요청**합니다.

### 직접 확인하는 법 (참고)

1. [ai.azure.com](https://ai.azure.com) → **모델 카탈로그**
2. 쓰려는 모델 클릭 → 상세 화면에서 **사용 가능한 지역** 확인
3. 그 지역으로 리소스를 만듭니다

## 2. Foundry 리소스 + 프로젝트 만들기 (20분)

이 한 번의 작업으로 **리소스와 첫 프로젝트가 같이** 만들어집니다.

1. [portal.azure.com](https://portal.azure.com) 접속 → 상단 검색창에 **리소스 만들기**

2. 검색창에 **Foundry** 를 입력하고 선택합니다.

3. 아래처럼 채웁니다.

    | 항목 | 값 |
    |---|---|
    | 구독 | **교육용 구독** (하나만 보입니다) |
    | 리소스 그룹 | **기존 선택** → `rg-ai901-<내 번호>` |
    | 지역 | **내 번호의 리전** — 01~20 `East US` / 21~40 `West US 3` |
    | 이름 | `ai901-<번호>-<이니셜>` (영문 소문자·숫자·하이픈) |
    | 프로젝트 이름 | `proj-ai901` |

    !!! info "프로젝트 이름 칸이 같은 화면에 있습니다"
        이 칸이 **리소스 안에 만들어질 첫 프로젝트**의 이름입니다.
        전원 똑같이 `proj-ai901` 로 쓰세요. 리소스 이름과 달리 **전 세계 중복과 무관**합니다.

    !!! danger "“새로 만들기”가 아니라 “기존 선택”입니다"
        리소스 그룹 칸에서 **드롭다운을 열어 `rg-ai901-<내 번호>` 를 고르세요.**
        **새로 만들기**를 누르면 권한이 없어 실패합니다 (Lab 00에서 확인한 그것입니다).

    !!! warning "이름은 전 세계에서 겹치면 안 됩니다"
        `ai901-01-nrk` 처럼 **번호 + 본인 이니셜**로 지으세요.
        이미 쓰는 이름이면 "사용할 수 없음"이 뜹니다. 뒤에 숫자를 더 붙이면 됩니다.

        **정한 이름을 환경 기록표에 적어 두세요.** Lab 02에서 엔드포인트를 만들 때 씁니다.

4. **검토 + 만들기** → **만들기**

5. 배포가 끝날 때까지 기다립니다. **1~3분** 걸립니다.

6. **리소스로 이동**을 누릅니다.

!!! success "한 번에 두 개가 만들어졌습니다"
    | 만들어진 것 | 이름 | 무엇인가 |
    |---|---|---|
    | Foundry **리소스** | `ai901-<번호>-<이니셜>` | 지역·요금·할당량이 붙는 **바깥 그릇** |
    | Foundry **프로젝트** | `proj-ai901` | 모델 배포·에이전트가 들어갈 **작업 공간** |

    프로젝트는 이 리소스의 **첫 프로젝트**라서 포털에서 `default` 태그가 붙어 보입니다.

!!! question "리소스 그룹이 뭔가요"
    관련된 리소스를 담는 **폴더**입니다. 4일 동안 만드는 것을 전부 이 안에 모아 두면
    정리가 쉽습니다.

!!! danger "내 리소스 그룹을 지우지 마세요"
    그룹에 **내 권한이 걸려 있습니다.** 그룹을 지우면 권한도 함께 사라져서
    그 뒤 실습을 못 하게 됩니다. 4일차 Lab 16에서는 **그룹 안의 리소스만** 지웁니다.

## 3. Foundry 포털에서 내 프로젝트 확인 (5분)

프로젝트는 2절에서 **이미 만들어졌습니다.** 여기서는 **확인만** 합니다.

1. [ai.azure.com](https://ai.azure.com) (Foundry 포털) 에 **같은 계정**으로 접속합니다.

2. 우상단 **New Foundry** 토글이 켜져 있는지 봅니다. 이 가이드는 새 화면 기준입니다.

3. 좌상단 프로젝트 선택에서 **`proj-ai901`** 이 보이는지 확인하고 고릅니다.

    !!! danger "여기서 “새 프로젝트 만들기”를 누르지 마세요"
        누르면 **두 번째 프로젝트**가 생겨서 뒤 랩에서 어느 쪽인지 헷갈립니다.
        우리가 쓸 것은 2절에서 만들어진 `proj-ai901` **하나**입니다.

4. 프로젝트 홈 화면이 열리면 됩니다.

    !!! note "프로젝트 엔드포인트는 3일차에 씁니다"
        프로젝트 홈에 **프로젝트 엔드포인트**가 보입니다.

        ```text
        https://<리소스이름>.services.ai.azure.com/api/projects/proj-ai901
        ```

        Lab 09(에이전트 코드 호출)에서 쓰니 **지금은 위치만** 기억해 두세요.
        Lab 02에서 쓰는 **리소스 엔드포인트와는 다른 주소**입니다.

!!! question "프로젝트를 더 만들려면"
    포털 우상단 **Manage** → 왼쪽 **Resource details** → **Add project**.
    4일 과정에서는 하나로 충분합니다.

## 🔧 안 될 때

??? failure "“리소스 만들기”에서 Foundry가 검색되지 않습니다"
    - 검색어를 **`Foundry`** 또는 **`AI Foundry`** 로 바꿔 보세요
    - 포털 언어가 영어면 `Create a resource` → `Foundry`
    - 구독 칸에 **교육용 구독**이 선택돼 있는지 확인하세요

??? failure "이름이 “이미 사용 중”이라고 나옵니다"
    Foundry 리소스 이름은 **전 세계에서 유일**해야 합니다.
    `ai901-01-nrk-0310` 처럼 뒤에 숫자를 붙이세요.

??? failure "리소스 그룹에서 “새로 만들기”가 실패합니다"
    **정상입니다.** 여러분은 새 리소스 그룹을 만들 권한이 없습니다.

    드롭다운을 열어 **이미 있는 `rg-ai901-<내 번호>`** 를 고르세요.
    Lab 00의 4절에서 확인한 권한 경계가 바로 이것입니다.

??? failure "리소스 그룹 드롭다운이 비어 있습니다"
    1. 구독 칸에 **교육용 구독**이 선택돼 있는지 먼저 확인하세요
    2. 우상단 프로필에서 **배부받은 계정**으로 로그인됐는지 확인하세요
    3. 그래도 비어 있으면 손을 드세요

??? failure "내 번호의 리전이 목록에 없습니다"
    목록이 길어서 눈에 안 띄는 경우가 대부분입니다.

    1. 지역 드롭다운의 **검색창에 `East US`(또는 `West US 3`)** 를 직접 입력하세요
       — 검색하면 `East US` 와 `East US 2` 가 **둘 다** 나옵니다. 숫자 없는 쪽입니다
    2. 포털이 한국어면 **미국 동부** / **미국 서부 3** 로 표시됩니다
    3. 그래도 없으면 **손을 드세요.** 임의로 고르지 마세요 —
       다른 리전에 만들면 뒤 랩에서 모델이 안 보이거나 할당량이 부족합니다

??? failure "“할당량이 부족합니다” / 더 만들 수 없다고 나옵니다"
    `InsufficientQuota` 계열 메시지입니다.

    **내 번호의 리전이 맞는지 먼저 확인하세요.** 번호와 다른 리전에 만들려 했다면
    그 리전이 이미 다 찬 것입니다 (리전당 30개 한도).
    맞는 리전으로 다시 시도하고, 그래도 나면 손을 드세요.

??? failure "Foundry 포털(ai.azure.com)에 리소스가 안 보입니다"
    1. **같은 계정**으로 로그인했는지 확인 (우상단 프로필)
    2. 우상단 **디렉터리 전환**에서 교육용 디렉터리가 선택돼 있는지 확인
    3. 리소스 배포가 아직 끝나지 않았을 수 있습니다. **2분 뒤 새로고침**
    4. 그래도 없으면 Azure 포털에서 리소스가 **"배포 성공"** 상태인지 확인

??? failure "만들기 화면에 프로젝트 이름 칸이 없습니다"
    **Foundry**가 아닌 다른 리소스를 고른 것입니다 (Azure OpenAI 단독 등).

    뒤로 가서 검색창에 **`Foundry`** 를 입력하고 **Foundry** 를 고르세요.
    프로젝트 이름 칸은 Foundry 리소스에만 있습니다.

??? failure "프로젝트가 안 보이거나 프로젝트에서 권한 오류가 납니다"
    권한 반영에 시간이 걸릴 수 있습니다.

    - 리소스가 **`rg-ai901-<내 번호>` 안에** 만들어졌는지 먼저 확인하세요
      (다른 그룹에 만들었다면 권한이 없습니다)
    - 5분 뒤 다시 시도 · 브라우저에서 **로그아웃 → 재로그인**
    - 그래도 안 되면 손을 드세요

??? failure "화면 구성이 가이드와 다릅니다"
    Foundry 포털은 업데이트가 잦습니다. **메뉴 이름으로 찾으세요.**
    위치가 바뀌었을 뿐 기능은 같습니다. 못 찾겠으면 손을 드세요.

## 💡 시험에 나오는 지점

!!! note "★ 이 Lab에서 만든 것이 그대로 출제됩니다"
    - **"지역(리전)을 정하는 단위는?"** → 프로젝트가 아니라 **리소스**
    - **"모델 배포와 에이전트가 들어가는 곳은?"** → **프로젝트**
    - **"리전 선택 시 가장 먼저 볼 것은?"** → **모델 가용성**
    - **포털이 둘을 한 번에 만들어 주더라도** → 지역·과금·할당량은 **리소스**,
      모델 배포·에이전트는 **프로젝트**

    리소스와 프로젝트를 뒤바꾼 선택지가 단골 오답입니다.
    "한 화면에서 만들었으니 같은 것"이라고 묶으면 틀립니다.
