    - 확보형으로 바뀌거나 비싼 모델을 배포해 두면 모르는 새 소진됩니다
    - 교육용 구독은 **다음 기수도 씁니다.** 남겨두면 다음 사람 환경이 더러워집니다

    **쓰지 않는 건 지운다** — 클라우드의 기본 습관입니다.

## 1. 왜 그룹은 남기나 (2분)

!!! danger "리소스 그룹 자체를 지우면 안 됩니다"
    여러분의 권한은 **`rg-ai901-<번호>` 그룹에 걸려 있습니다.**
    그룹을 지우면 **권한도 함께 사라져서** 아무것도 못 하게 됩니다.

    ```text
    rg-ai901-01  ← 권한이 여기 붙어 있다
      ├─ ai901-01-xxx     (Foundry 리소스)   ← 이것들만 지운다
      └─ speech-ai901-01  (Speech 리소스)    ← 이것들만 지운다
    ```

    **그룹 안의 리소스만** 지우세요. 빈 그룹은 과금되지 않습니다.
    그룹은 수업 뒤 **강사가 일괄 정리**합니다.

!!! note "★ 시험과 이어지는 지점"
    "리소스 그룹을 삭제하면 어떻게 되는가?" → **안에 든 리소스가 전부 함께 삭제된다**
    이건 사실입니다. 다만 **그룹에 걸린 역할 할당도 함께 사라진다**는 점이
    실무에서 자주 사고를 냅니다. 오늘 그걸 피하는 방식으로 정리합니다.

## 2. 내 그룹 안의 리소스 지우기 (5분)

1. [portal.azure.com](https://portal.azure.com) → 검색창에 **리소스 그룹**
2. **`rg-ai901-<내 번호>`** 클릭
3. 안에 무엇이 있는지 **한 번 훑어보세요** (4일 동안 만든 것들입니다)
4. 목록 맨 위의 **체크박스를 눌러 전체 선택**합니다
5. 상단 **삭제** 를 누릅니다
6. 확인 입력을 요구하면 화면이 지시하는 문자열(보통 `delete`)을 입력합니다
7. **삭제**

!!! warning "삭제는 되돌릴 수 없습니다"
    에이전트, 업로드한 규정 문서, 모델 배포가 전부 사라집니다.
    **남기고 싶은 게 있으면 먼저 내려받으세요.**

    로컬 폴더(`ai901/`)의 코드는 그대로 남습니다. 지워지는 건 Azure 쪽뿐입니다.

삭제에 **2~5분** 걸립니다.

!!! tip "그룹 삭제 버튼을 누르지 않도록 주의하세요"
    화면 상단에는 **리소스 그룹 삭제** 버튼도 함께 있습니다.
    우리가 누를 것은 **리소스를 선택한 뒤의 삭제** 입니다.

## 3. 확인 (3분)

### ① 그룹이 비었는지

그룹 이름 자체는 **남아 있는 게 정상**입니다.

## 4. 로컬 정리 (2분)

Azure 쪽은 지웠지만 **노트북의 `.env` 에는 키가 남아 있습니다.**

!!! danger "`.env` 는 비밀번호 파일입니다"
    - 지운 리소스의 키라 이제 쓸모없지만, **습관을 들이세요**
    - 절대 GitHub에 올리지 마세요. `.gitignore` 에 `.env` 를 넣는 게 기본입니다

```bash
# .gitignore 를 만든다면
echo ".env" >> .gitignore
echo ".venv/" >> .gitignore
```

**코드 파일은 지우지 마세요.** 나중에 본인 구독을 만들면 그대로 쓸 수 있습니다.

!!! tip "집에서 이어서 하고 싶다면"
    `requirements.txt` 와 코드 파일을 그대로 두고,
    본인 구독(Azure for Students 등)에서 Lab 01·02를 다시 하면 됩니다.
    `.env` 의 세 값만 새로 채우면 나머지 코드는 전부 그대로 돕니다.

## 🔧 안 될 때

??? failure "삭제가 실패합니다"
    - 다른 리소스가 참조 중일 수 있습니다. **2~3분 뒤 다시** 시도하세요
    - 전체 선택이 아니라 **하나씩** 지워 보세요 (프로젝트 → 리소스 순서)
    - 그래도 안 되면 손을 드세요. 강사가 `cleanup.sh` 로 일괄 정리합니다

??? failure "삭제 중에서 멈춰 있습니다"
    5~10분 걸릴 수 있습니다. 새로고침해 보세요.
    오래 걸려도 **백그라운드에서 진행**되니 퇴실하셔도 됩니다.

??? failure "실수로 리소스 그룹을 지웠습니다"
    괜찮습니다. **지금은 마지막 랩이라 실습에 지장이 없습니다.**
    강사에게 알려만 주세요. 다음 기수 준비 때 다시 만듭니다.

    (수업 중이었다면 권한이 사라져서 실습이 중단됐을 겁니다. 그래서 2절에서 주의를 드렸습니다.)

??? failure "리소스 그룹이 보이지 않습니다"
    로그인 계정을 확인하세요 (우상단 프로필).
    배부받은 계정이 아니면 내 그룹이 보이지 않습니다.
