## 1. 리소스 그룹 하나만 지우면 됩니다 (5분)

Lab 01에서 **`rg-ai901`** 이라는 폴더 하나에 전부 모아 뒀습니다. 그래서 간단합니다.

1. [portal.azure.com](https://portal.azure.com) → 검색창에 **리소스 그룹**
2. **`rg-ai901`** 클릭
3. 안에 무엇이 있는지 **한 번 훑어보세요** (4일 동안 만든 것들입니다)
4. 상단 **리소스 그룹 삭제**
5. 확인을 위해 **그룹 이름을 그대로 입력**하라고 합니다 → `rg-ai901` 입력
6. **삭제**

!!! warning "삭제는 되돌릴 수 없습니다"
    에이전트, 업로드한 규정 문서, 배포가 전부 사라집니다.
    **남기고 싶은 게 있으면 먼저 내려받으세요.**

    로컬 폴더(`ai901/`)의 코드는 그대로 남습니다. 지워지는 건 Azure 쪽뿐입니다.

삭제에 **2~5분** 걸립니다.

## 3. 로컬 정리 (2분)

Azure 쪽은 지웠지만 **노트북의 `.env` 에는 키가 남아 있습니다.**

!!! danger "`.env` 는 비밀번호 파일입니다"
    - 지운 리소스의 키라 이제 쓸모없지만, **습관을 들이세요**
    - 절대 GitHub에 올리지 마세요. `.gitignore` 에 `.env` 를 넣는 게 기본입니다

```bash
# .gitignore 를 만든다면
echo ".env" >> .gitignore
echo ".venv/" >> .gitignore
```

**코드 파일은 지우지 마세요.** 나중에 다시 환경을 만들면 그대로 쓸 수 있습니다.
