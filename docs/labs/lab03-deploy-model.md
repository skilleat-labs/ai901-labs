## 0. 어제 만든 배포를 다시 엽니다

새로 만들지 않습니다. **어제 배포한 `gpt-4o-mini` 의 설정을 열어** 하나씩 확인합니다.

1. [ai.azure.com](https://ai.azure.com) → 내 프로젝트 → **배포(Deployments)**
2. `gpt-4o-mini` 클릭
3. **편집** 또는 설정 화면을 엽니다

!!! note "배포할 때 정하는 네 가지"
    | | 무엇 | 어디서 다루나 |
    |---|---|---|
    | 1 | **배포 유형** | 1절 |
    | 2 | **모델 버전** | 2절 |
    | 3 | **속도 제한 (TPM)** | 3절 |
    | 4 | **가드레일 (컨텐츠 필터)** | 4절 |

    **★ 이 네 가지가 시험에 그대로 나옵니다.**

## 1. 배포 유형 (8분)

| | 종량제 (Pay-as-you-go) | 확보형 (Provisioned / PTU) |
|---|---|---|
| 결제 | **쓴 만큼** | **확보한 만큼** (안 써도 과금) |
| 성능 | 공유 — 몰리면 느려질 수 있음 | 보장됨 |
| 적합 | 요청량이 **불규칙**할 때 | 일정 성능을 **보장**해야 할 때 |

### 종량제 안에도 갈래가 있습니다 — 어제 겪은 그것

| | Standard (지역) | **Global Standard** |
|---|---|---|
| 처리 위치 | **내 지역 안에서** | 전 세계로 분산 |
| 할당량 | 지역별로 따로 | 훨씬 넉넉 |
| 적합 | 데이터 소재지 규제가 있을 때 | **일반적인 경우** |

!!! note "어제 `Global Standard` 를 고른 이유가 이겁니다"
    할당량 규모가 다릅니다. 이 구독 기준으로 지역형 `Standard` 는 **200K TPM**,
    `Global Standard` 는 **2,000K TPM** 입니다. **10배 차이**입니다.

    32명이 나눠 쓰는 상황에서는 `Global Standard` 라야 여유가 생깁니다.

    **★ 시험 포인트** — "데이터가 특정 국가 안에서 처리되어야 한다" 가 조건이면
    **지역형(Standard 또는 DataZone)** 이고, 그 외에는 Global 이 기본입니다.

### 확인해 보세요

배포 화면에서 현재 유형이 무엇으로 되어 있는지 봅니다. 어제 만든 건 **Global Standard** 입니다.

!!! question "우리는 왜 종량제인가요"
    수업에서는 하루에 몇 번만 호출합니다. 확보형으로 잡으면 **수업하지 않는 밤새도록 과금**됩니다.
    크레딧이 하루 만에 사라집니다.

!!! note "★ 시험에 이렇게 나옵니다"
    > "사내 챗봇을 배포했는데 요청량이 시간대별로 들쭉날쭉하고 야간에는 호출이 거의 없다.
    > 비용 측면에서 가장 적합한 배포 유형은?"

    → **종량제.** "요청량이 불규칙하다"가 나오면 종량제입니다.
    반대로 "일정 성능을 보장해야 한다"가 나오면 확보형입니다.

## 2. 모델 버전 (5분)

배포 화면에서 **버전**과 **업데이트 정책**을 확인합니다.

| 선택 | 의미 | 언제 |
|---|---|---|
| **버전 고정** | 항상 같은 동작 | **프로덕션** — 출력이 바뀌면 안 될 때 |
| **자동 업데이트** | 최신 개선을 자동 반영 | 개발·실험 |

!!! warning "모델은 언젠가 종료됩니다 (retire)"
    오래된 버전은 Microsoft가 공지 후 서비스를 종료합니다.
    버전을 고정했다면 **종료 공지를 챙겨 봐야 합니다.** 안 그러면 어느 날 갑자기 멈춥니다.

## 3. 속도 제한 — TPM (10분)

**TPM = Tokens Per Minute, 분당 처리 가능한 토큰 수**입니다.

| 알아야 할 것 | 설명 |
|---|---|
| 무엇을 세나 | **입력 토큰 + 출력 토큰의 합** |
| 높이면 | 동시에 더 많은 요청을 받을 수 있습니다 |
| 어디서 빠지나 | **구독 전체 할당량에서 차감** — 모델·리전별 총량을 여러 배포가 나눠 씁니다 |

### 해보세요

1. 배포 설정에서 **TPM 값**을 확인합니다
2. 값을 조금 올려 봅니다 (예: 10K → 20K)
3. **저장**합니다

!!! tip "어제 429 오류가 났던 분"
    같은 교실에서 동시에 요청이 몰리면 TPM 한도에 걸립니다.
    여기서 올려두면 오늘 실습이 편해집니다.

!!! note "★ 시험에 이렇게 나옵니다"
    > "429 Too Many Requests 오류가 반복된다. 무엇을 조정해야 하는가?"

    → **TPM 할당량.** 키나 엔드포인트 문제가 아닙니다.

## 4. 가드레일 — 컨텐츠 필터 (10분)

모델이 유해한 내용을 **받지도, 내보내지도** 않게 막는 장치입니다.

### 네 가지 범주

| 범주 | 무엇을 막나 |
|---|---|
| 증오 · 공정성 | 특정 집단을 겨냥한 차별적 표현 |
| 성적 콘텐츠 | 부적절한 성적 표현 |
| 폭력 | 폭력·상해를 조장하는 내용 |
| 자해 | 자해를 조장하거나 방법을 알려주는 내용 |

각 범주마다 **심각도 단계**를 조절할 수 있습니다.

### 가장 중요한 것 — 입력과 출력에 따로 적용됩니다

```text
사용자 입력 ──[입력 필터]──> 모델 ──[출력 필터]──> 사용자에게
```

!!! note "★ 시험에 이렇게 나옵니다"
    > "입력은 통과했는데 출력이 차단됐다. 어느 설정을 조정해야 하는가?"

    → **출력 필터.** 둘이 따로 설정된다는 걸 알아야 풀립니다.

### 확인해 보세요

1. 배포 설정에서 **컨텐츠 필터** 항목을 찾습니다
2. 현재 적용된 필터를 열어 **네 범주와 심각도**를 눈으로 확인합니다
3. **입력(프롬프트)** 과 **출력(완성)** 이 나뉘어 있는지 봅니다

!!! warning "필터를 끄지 마세요"
    학생 구독에서는 보통 기본 필터가 고정되어 있습니다.
    바꿀 수 있더라도 **수업 중에는 기본값 그대로** 두세요.

## 5. ✅ 체크포인트

!!! success "여기까지 됐으면 통과입니다"
    - [ ] 내 배포의 **배포 유형**이 무엇인지 말할 수 있다
    - [ ] **버전 고정 vs 자동 업데이트**의 차이를 말할 수 있다
    - [ ] **TPM** 값을 확인했고, 무엇을 세는지 안다 (입력+출력 토큰)
    - [ ] **컨텐츠 필터 4범주**를 찾았고, **입력과 출력이 따로**라는 걸 확인했다

**설정 화면을 캡처해 두면** 오늘 저녁 복습에 좋습니다.

## 🔧 안 될 때

??? failure "배포 설정에서 TPM을 바꿀 수 없습니다"
    학생 구독은 할당량 상한이 낮게 묶여 있을 수 있습니다.

    - 현재 값만 확인하고 넘어가세요. **실습에는 지장 없습니다**
    - 오늘 429가 반복되면 손을 드세요

??? failure "컨텐츠 필터 항목이 안 보입니다"
    배포 상세 화면 또는 프로젝트의 **안전성(Safety)** 메뉴에 있습니다.
    포털 구성이 자주 바뀌니 **메뉴 이름으로 검색**해 보세요. 못 찾으면 손을 드세요.

??? failure "설정을 바꿨더니 배포가 \"업데이트 중\"에서 멈춰 있습니다"
    1~2분 걸립니다. 새로고침해 보세요.
    5분 넘게 멈춰 있으면 손을 드세요.
