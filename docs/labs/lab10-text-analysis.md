## 0. 두 가지 길이 있습니다 (5분)

!!! note "★★ 10강의 핵심이자 시험 최다 출제 지점"
    | | 범용 모델 (gpt-5.4-mini) | 전용 서비스 (Azure Language) |
    |---|---|---|
    | 방식 | **프롬프트로 시킨다** | **메서드를 호출한다** |
    | 반환 | 자유 텍스트 (형식 요청 가능) | **구조화된 결과 + 신뢰도 점수** |
    | 장점 | 유연함 · 여러 작업을 한 번에 | 일관된 형식 · 점수 · 저렴 |
    | 단점 | 형식이 흔들릴 수 있음 | 정해진 작업만 |

    **판단 기준** — "시스템이 쓸 거면 전용 서비스"로 외우면 **틀립니다.**
    범용 모델도 JSON 을 뱉게 할 수 있습니다 (이 랩에서 바로 그걸 합니다).

    진짜 갈림길은 네 가지입니다.

    | 이런 조건이면 | 고를 것 |
    |---|---|
    | **신뢰도 점수(confidence score)** 가 필요하다 | **전용 서비스** |
    | 스키마가 **절대 흔들리면 안 된다** (계약된 형식) | **전용 서비스** |
    | 대량 처리라 **단가·지연**이 중요하다 | **전용 서비스** |
    | 작업이 **정해진 목록에 없다** (요약 + 번역 + 분류를 한 번에 등) | **범용 모델** |

    한 줄로 줄이면 — **정해진 작업을 확실하게**는 전용 서비스,
    **정해지지 않은 작업을 유연하게**는 범용 모델입니다.

오늘은 **범용 모델**로 직접 만들고, 전용 서비스는 차이를 눈으로 비교합니다.

## 1. `analyze_general.py` (15분)

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI(
    base_url=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("API_KEY"))

review = """지난주에 강남점에서 산 무선 이어폰인데요,
음질은 생각보다 훨씬 좋았습니다. 다만 배송이 5일이나 걸려서 답답했고
포장도 좀 허술했어요. 김민수 매니저님이 친절하게 응대해 주신 건 좋았습니다."""

prompt = f"""다음 고객 리뷰를 분석해서 JSON으로만 답해라.

{{
  "감정": "긍정 | 부정 | 중립",
  "엔터티": ["사람·장소·조직·제품"],
  "키구문": ["핵심 주제어 3개"],
  "요약": "한 문장"
}}

리뷰:
{review}"""

message = client.responses.create(
    model=os.getenv("MODEL_DEPLOYMENT_NAME"),
    input=prompt)

print(message.output_text)
```

```bash
python analyze_general.py
```

### 나오는 결과 — 예시

```json
{
  "감정": "부정",
  "엔터티": ["강남점", "무선 이어폰", "김민수 매니저"],
  "키구문": ["음질", "배송 지연", "포장 허술"],
  "요약": "음질과 응대는 좋았지만 배송이 늦고 포장이 허술해 전반적으로 부정적인 리뷰다."
}
```

!!! warning "★ 감정이 부정으로 나와도, 중립으로 나와도 맞습니다"
    옆 사람과 값이 다를 겁니다. **틀린 게 아니라 이 랩의 핵심입니다.**

    이 리뷰에는 좋은 점(음질·응대)과 나쁜 점(배송·포장)이 **둘 다** 있습니다.
    그런데 우리가 준 선택지는 `긍정 | 부정 | 중립` 셋뿐입니다.
    **"혼합"이라는 칸이 없으니 모델이 셋 중 하나를 고를 수밖에 없습니다.**
    나쁜 점을 더 무겁게 보면 `"부정"`, 둘이 상쇄된다고 보면 `"중립"` 입니다.

    같은 리뷰를 **전용 서비스**에 넣으면 `mixed` 라고 답합니다. 3절에서 확인합니다.
    엔터티나 키구문도 개수·표기가 조금씩 다를 수 있습니다 (`김민수` vs `김민수 매니저`).

!!! question "네 가지 작업을 한 번에 했습니다"
    전용 서비스였다면 **감정 분석 · 엔터티 인식 · 키 구문 추출 · 요약**을
    각각 따로 호출해야 합니다. 범용 모델의 장점이 이겁니다.

## 2. 약점을 직접 확인하세요 (5분)

같은 코드를 **3번 더** 돌리고, **세 결과를 나란히 놓고** 보세요.
무엇이 같고 무엇이 달라지는지가 핵심입니다.

| 보는 곳 | 대개 이렇게 됩니다 | 그래서 뭐가 문제인가 |
|---|---|---|
| 감정 · 엔터티 | 대체로 **같게** 나옵니다 | 판정 자체는 꽤 안정적입니다 |
| **키구문** | `"포장 허술"` → `"포장 상태"` 처럼 **표기가 바뀝니다** | 같은 뜻인데 문자열이 달라 **집계가 안 됩니다** |
| **요약** | **매번 다른 문장**이 나옵니다 | 생성이라 표현이 고정되지 않습니다 |
| **신뢰도 점수** | **아예 없습니다** | 이 판정을 얼마나 믿을지 알 수 없습니다 |

!!! question "세 번 다 비슷하게 나왔는데요?"
    그게 정상입니다. **크게 흔들리는 걸 보라는 게 아닙니다.**
    같은 입력인데 **요약 문장과 키구문 표기가 매번 조금씩 달라진다**는 것, 그거면 충분합니다.

    리뷰 1,000건을 이 코드로 돌려 "포장" 관련 불만을 세야 한다고 해보세요.
    `포장 허술` · `포장 상태` · `포장` 이 섞여 나오면 **숫자를 못 셉니다.**
    전용 서비스는 같은 입력에 **같은 라벨과 같은 점수**를 줍니다. 그 차이가 선택의 기준입니다.

!!! warning "여기가 범용 모델의 한계입니다"
    - **표현이 고정되지 않습니다** → 결과를 모아서 집계·비교하기 어렵습니다
    - 가끔 JSON 앞뒤에 설명이 붙습니다 → 파싱이 깨집니다
    - **신뢰도 점수가 없습니다** → "이 감정 판정을 얼마나 믿을 수 있나"를 알 수 없습니다

    온도를 **0**으로 낮추면 많이 안정됩니다 — 다만 **보장은 아닙니다.** ([Lab 06](lab06-parameters.md))

    ```python
    message = client.responses.create(
        model=os.getenv("MODEL_DEPLOYMENT_NAME"),
        input=prompt,
        temperature=0)
    ```

## 3. 전용 서비스는 무엇이 다른가 — 직접 돌려봅니다 (10분)

!!! success "새 리소스도, 새 키도 필요 없습니다"
    Lab 01에서 만든 Foundry 리소스가 **Language 도 같이 제공합니다.**
    키는 지금 쓰는 `API_KEY` 그대로고, **주소만 다릅니다.**

    | | 주소 |
    |---|---|
    | 모델 호출 (Lab 04~) | `https://<리소스명>.openai.azure.com/openai/v1` |
    | **Language 호출 (지금)** | `https://<리소스명>.cognitiveservices.azure.com/` |

패키지를 설치합니다.

```ini title="requirements.txt 에 추가"
azure-ai-textanalytics==5.4.0
```

```bash
pip install -r requirements.txt
```

`.env` 에 **한 줄 추가**합니다. `<리소스명>` 은 지금 쓰는 엔드포인트 주소에서 그대로 가져오세요.

```ini
LANGUAGE_ENDPOINT=https://<리소스명>.cognitiveservices.azure.com/
```

```python title="analyze_language.py"
import os
from dotenv import load_dotenv
from azure.core.credentials import AzureKeyCredential
from azure.ai.textanalytics import TextAnalyticsClient

load_dotenv()
client = TextAnalyticsClient(
    endpoint=os.getenv("LANGUAGE_ENDPOINT"),
    credential=AzureKeyCredential(os.getenv("API_KEY")))

review = """지난주에 강남점에서 산 무선 이어폰인데요,
음질은 생각보다 훨씬 좋았습니다. 다만 배송이 5일이나 걸려서 답답했고
포장도 좀 허술했어요. 김민수 매니저님이 친절하게 응대해 주신 건 좋았습니다."""

result = client.analyze_sentiment(documents=[review])[0]

print("문서 전체:", result.sentiment)
print("  긍정", result.confidence_scores.positive,
      "/ 중립", result.confidence_scores.neutral,
      "/ 부정", result.confidence_scores.negative)

for s in result.sentences:
    print(f"  [{s.sentiment}] {s.text.strip()}")
```

```bash
python analyze_language.py
```

### 나오는 결과

```text
문서 전체: mixed
  긍정 0.65 / 중립 0.03 / 부정 0.32
  [positive] 지난주에 강남점에서 산 무선 이어폰인데요, 음질은 생각보다 훨씬 좋았습니다.
  [negative] 다만 배송이 5일이나 걸려서 답답했고 포장도 좀 허술했어요.
  [positive] 김민수 매니저님이 친절하게 응대해 주신 건 좋았습니다.
```

!!! question "★ 2절에서 본 것과 비교하세요"
    범용 모델은 `긍정 | 부정 | 중립` 중 하나를 **골라야** 했습니다. 그래서 `"부정"` 이 나왔죠.
    전용 서비스는 **`mixed`** 라고 답합니다. 혼합을 혼합이라고 말할 수 있습니다.

    거기에 **점수**가 붙고, **문장별로** 어디가 긍정이고 어디가 부정인지까지 나눠 줍니다.
    그리고 **몇 번을 돌려도 같은 값**입니다. 2절에서 요약 문장이 매번 달라지던 것과 반대입니다.

!!! note "★ 반환값의 차이가 시험에 나옵니다"
    | | 범용 모델 | 전용 서비스 |
    |---|---|---|
    | 감정 | `"부정"` · `"중립"` — 셋 중 하나를 고른 문자열 | **`mixed`** — 혼합을 혼합이라고 답한다 |
    | 신뢰도 | **없다** | `confidence_scores` (0.65 / 0.03 / 0.32) |
    | 세분화 | 문서 하나에 값 하나 | **문장별 감정**까지 |
    | 형식 | 요청한 대로 (표현이 흔들림) | **항상 같은 객체 · 같은 값** |
    | 할 수 있는 것 | 요약·번역·분류를 **한 번에** | 감정 하나만, 대신 **확실하게** |

    **"신뢰도 점수가 필요하다"** 가 문제에 나오면 → **전용 서비스**입니다.
    이게 3강에서 배운 "생성형 AI가 이전 AI를 대체하지 않는다"의 실체입니다.

## 🔧 안 될 때

??? failure "JSON 앞뒤에 설명이 붙습니다"
    프롬프트에 강하게 지시하세요.

    ```text
    JSON만 출력하고 다른 말은 하지 마라. 코드블록 표시(```)도 쓰지 마라.
    ```

    그리고 `temperature=0` 을 넣으세요. 실무에서는 파싱 실패에 대비해
    `try/except` 로 감싸고 재시도합니다.

??? failure "한글이 깨집니다"
    파일을 **UTF-8** 로 저장했는지 확인하세요.
    VS Code 우하단에서 인코딩을 확인할 수 있습니다.

??? failure "f-string 안의 중괄호에서 오류가 납니다"
    f-string 안에서 JSON의 `{` 는 **`{{`** 로 써야 합니다.
    위 코드가 그렇게 되어 있으니 그대로 복사하세요.

??? failure "Language 호출에서 401 · 404 가 납니다"
    주소부터 확인하세요. **`.openai.azure.com` 이 아니라 `.cognitiveservices.azure.com`** 입니다.
    끝의 슬래시까지 포함하고, `/openai/v1` 같은 경로는 **붙이지 않습니다.**

    ```python
    print(os.getenv("LANGUAGE_ENDPOINT"))
    ```

    주소가 맞는데도 안 되면 리소스에 Language 기능이 없는 경우입니다. **손을 드세요.**

??? failure "엔터티를 제대로 못 찾습니다"
    작은 모델의 한계입니다. 리뷰 문장을 더 명확하게 바꾸거나,
    프롬프트에 예시를 하나 넣어 보세요 (few-shot).
