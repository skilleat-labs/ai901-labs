**선행** [Lab 05](lab05-chat-memory.md) · [Lab 06](lab06-parameters.md) 완료 · **예상 시간** 25분 · **비용** 약 $0.02 미만

## 1. 시스템 메시지란 (5분)

`messages` 목록 **맨 앞**에 넣는 지시문입니다. 대화 내내 유지됩니다.

| | `system` | `user` |
|---|---|---|
| 넣는 것 | 역할 · 규칙 · 말투 · 금지사항 | 그때그때 하는 질문 |
| 지속 | **대화 내내** | 그 턴만 |
| 누가 씀 | **개발자** | 사용자 |

!!! note "★ 시험 포인트"
    "챗봇의 역할과 규칙을 지정하는 곳" → **시스템 메시지**.
    `user` 에 넣으면 몇 턴 지나 흐려집니다.

## 2. `chat3.py` — 규칙을 거는 챗봇 (12분)

`chat2.py` 를 복사해서 `chat3.py` 로 만들고, **두 군데만** 고칩니다.

```python
SYSTEM = """너는 사내 규정 안내 도우미다.
- 제공된 규정 문서만 근거로 답한다.
- 근거 조항을 항상 함께 표시한다.
- 규정에 없는 내용은 '확인 필요'라고 답한다.
- 답변은 3문장 이내로 한다."""

messages = [{"role": "system", "content": SYSTEM}]
```

!!! warning "`messages = []` 를 `messages = [{"role": "system", ...}]` 로 바꾸는 것입니다"
    빈 목록으로 시작하던 걸, **시스템 메시지 하나를 담은 목록**으로 시작하게 바꿉니다.
    아래 `while` 문은 `chat2.py` 와 **완전히 동일**합니다.

전체는 이렇게 됩니다.

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI(
    base_url=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("API_KEY"))
MODEL = os.getenv("MODEL_DEPLOYMENT_NAME")

SYSTEM = """너는 사내 규정 안내 도우미다.
- 제공된 규정 문서만 근거로 답한다.
- 근거 조항을 항상 함께 표시한다.
- 규정에 없는 내용은 '확인 필요'라고 답한다.
- 답변은 3문장 이내로 한다."""

messages = [{"role": "system", "content": SYSTEM}]

while True:
    q = input("질문(종료는 exit): ")
    if q.lower() == "exit":
        break
    messages.append({"role": "user", "content": q})
    r = client.responses.create(model=MODEL, input=messages)
    answer = r.output_text
    print(answer)
    messages.append({"role": "assistant", "content": answer})
```

## 3. 근거가 될 문서를 넣습니다 (8분)

지금은 "제공된 규정 문서만 근거로"라고 해놓고 **문서를 안 줬습니다.**
`SYSTEM` 아래에 규정을 직접 붙입니다.

```python
규정 = """[사내 휴가 규정]
제3조 (연차) 입사 1년 이상 직원은 연 15일의 연차를 부여한다.
제4조 (신청) 연차는 사용 3일 전까지 시스템으로 신청한다.
제7조 (이월) 미사용 연차는 다음 해로 이월되지 않는다."""

SYSTEM = f"""너는 사내 규정 안내 도우미다.
- 아래 규정 문서만 근거로 답한다.
- 근거 조항을 항상 함께 표시한다.
- 규정에 없는 내용은 '확인 필요'라고 답한다.
- 답변은 3문장 이내로 한다.

{규정}"""
```

### 세 가지를 물어보세요

| 질문 | 기대하는 답 |
|---|---|
| `연차가 며칠인가요?` | 15일 + **제3조** 인용 |
| `연차를 언제까지 신청해야 하나요?` | 3일 전 + **제4조** 인용 |
| `병가는 며칠인가요?` | **"확인 필요"** — 규정에 없으니까 |

!!! success "세 번째가 핵심입니다"
    규정에 없는 걸 물었을 때 **지어내지 않고 "확인 필요"라고 답하면** 성공입니다.

    시스템 메시지 없이 같은 질문을 하면 모델이 그럴듯하게 **지어냅니다**(환각).
    한번 `SYSTEM` 을 지우고 물어보세요. 차이가 바로 보입니다.

## 🔧 안 될 때

??? failure "근거 조항을 표시하지 않습니다"
    시스템 메시지가 제대로 들어갔는지 확인하세요.

    ```python
    print(messages[0])      # system 메시지가 보여야 합니다
    ```

    그래도 안 되면 지시를 더 구체적으로 바꿉니다.
    `"반드시 '(제N조)' 형식으로 근거를 표시한다."`

??? failure "규정에 없는 것도 지어냅니다"
    - 온도를 **0**으로 낮춰 보세요 ([Lab 06](lab06-parameters.md))
    - 지시를 강하게: `"규정에 없으면 반드시 '확인 필요'라고만 답하고 추측하지 않는다."`
    - 작은 모델일수록 지시를 덜 따릅니다. 큰 모델에서 더 잘 지켜집니다

??? failure "f-string 에서 오류가 납니다"
    `SYSTEM = f\"\"\"...\"\"\"` 에서 **f** 를 빠뜨렸는지 확인하세요.
    f 가 없으면 `{규정}` 이 글자 그대로 들어갑니다.

??? failure "한글 변수명이 안 됩니다"
    Python은 한글 변수명을 허용합니다. 오류가 나면 파일 인코딩 문제일 수 있으니
    변수명을 `rules` 로 바꿔 보세요.

## 💡 2일차 마무리

오늘 만든 파일들입니다.

```text
ai901/
├── .env
├── verify.py        ← 1일차
├── call_model.py    ← 토큰 확인
├── chat1.py         ← 단일 질문 (기억 없음)
├── chat2.py         ← 멀티턴 (기억 있음)
├── params.py        ← 온도 실험
└── chat3.py         ← 시스템 메시지 + 근거 기반  ★
```

!!! quote "오늘의 한 줄"
    **모델을 바꾸는 게 아니라 프롬프트를 바꿉니다.**
    같은 모델도 시스템 메시지 하나로 완전히 다르게 동작합니다.

!!! note "★ 이 방식의 한계도 알아두세요"
    규정을 **프롬프트에 직접 넣는** 방식은 문서가 작을 때만 씁니다.
    문서가 수백 페이지면 토큰 한도를 넘습니다.

    그때는 **검색해서 관련 부분만 찾아 넣는** 방식(RAG)이나,
    **에이전트에 지식을 붙이는** 방식을 씁니다. **내일 Lab 08에서 합니다.**
