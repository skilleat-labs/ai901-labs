# Lab 00 — Azure 계정 준비 + 예산 알림

!!! warning "먼저 — 강사가 계정을 배부했습니까?"
    **배부받았다면(방식 ⓐ) 아래 1·2절은 건너뜁니다.** 구독과 예산 알림은 강사가 이미 만들어 두었습니다.
    배부받은 계정으로 [portal.azure.com](https://portal.azure.com) 에 로그인해서 **이것만** 확인하세요.

    - [ ] 로그인된다 (첫 로그인 시 비밀번호 변경·MFA 등록을 요구할 수 있습니다)
    - [ ] **구독** 목록에 구독이 하나 보인다
    - [ ] **리소스 그룹** 목록에 내 번호의 그룹(`rg-ai901-<번호>`)이 보인다

    세 개가 되면 **Lab 01 로 넘어가세요.** 안 되면 바로 손을 들어 주세요.

    각자 가입하는 방식(ⓑ)이라면 아래를 그대로 진행합니다.

!!! info "이 실습에서 하는 것 (방식 ⓑ)"
    **Azure for Students**로 구독을 만들고, **신용카드 없이** $100 크레딧을 받습니다.
    그리고 크레딧이 줄어들 때 메일이 오도록 **예산 알림**을 겁니다.

**선행** 없음 · **예상 시간** 35분 · **비용** 0원

---

## 0. 시작 전 — 두 가지만 확인하세요

!!! warning "학교 이메일이 필요합니다"
    `@kunsan.ac.kr` 로 끝나는 **학교 이메일**로 가입합니다.
    개인 Gmail·Naver 메일로는 학생 크레딧을 받을 수 없습니다.

    지금 학교 메일에 로그인이 되는지 먼저 확인하세요. 인증 메일을 받아야 합니다.

!!! danger "신용카드를 요구하는 화면이 나오면 잘못 들어온 것입니다"
    Azure에는 비슷한 가입 경로가 두 개 있습니다.

    | | 카드 | 크레딧 |
    |---|---|---|
    | **Azure for Students** ← 우리가 쓸 것 | **불필요** | $100 / 12개월 |
    | Azure 무료 계정 (일반) | **필요** | $200 / 30일 |

    카드 번호를 넣으라는 화면이 나오면 **멈추고 강사를 부르세요.**
    주소에 `/free/students` 가 들어 있는지 확인하면 됩니다.

---

## 1. Azure for Students 가입 (15분)

1. 브라우저에서 접속합니다.

    ```text
    https://azure.microsoft.com/ko-kr/free/students/
    ```

2. **[학생용 Azure 체험하기]** 버튼을 누릅니다.

3. Microsoft 계정으로 로그인합니다.

    !!! tip "어떤 계정으로 로그인하나요"
        **학교 이메일(`@kunsan.ac.kr`)로 Microsoft 계정을 만들어** 로그인하세요.
        이미 학교 계정이 Microsoft 365에 연결돼 있다면 그대로 로그인됩니다.

        개인 계정으로 로그인하면 뒤에서 학생 인증에 실패합니다.

4. **학생 인증**을 진행합니다. 학교 이메일 주소를 넣으면 Microsoft가 도메인을 확인합니다.

5. 이름·생년월일·국가를 입력하고, 휴대폰 번호로 본인 확인을 합니다.

6. 약관에 동의하고 완료합니다.

!!! success "여기까지 됐다면"
    **카드 정보를 한 번도 묻지 않았어야 합니다.** 물어봤다면 1번 주소를 다시 확인하세요.

---

## 2. 구독이 생겼는지 확인 (5분)

1. [portal.azure.com](https://portal.azure.com) 에 같은 계정으로 로그인합니다.

2. 상단 검색창에 **구독** 을 입력하고 들어갑니다.

3. 목록에 **Azure for Students** 가 보이면 성공입니다.

4. 구독을 클릭해서 **구독 ID**를 확인하고 메모해 두세요. 뒤 실습에서 씁니다.

### 크레딧 잔액 보는 법

포털 검색창에 **Education** 을 입력하면 **Azure Education Hub** 가 나옵니다.
여기 들어가면 **남은 크레딧**이 바로 보입니다. 4일 내내 가끔 확인하세요.

---

## 3. 예산 알림 걸기 (12분)

크레딧이 얼마나 줄었는지 매번 들어가 보긴 번거롭습니다. **메일로 오게** 만듭니다.

1. 포털 검색창에 **비용 관리** (또는 Cost Management) 를 입력하고 들어갑니다.

2. 왼쪽 메뉴에서 **예산(Budgets)** → **+ 추가** 를 누릅니다.

3. 범위가 **Azure for Students 구독**으로 되어 있는지 확인합니다.

4. 예산을 아래처럼 만듭니다.

    | 항목 | 값 |
    |---|---|
    | 이름 | `ai901-budget` |
    | 재설정 기간 | 월별 |
    | 금액 | **20** (USD) |
    | 통화 | USD |

    !!! question "왜 $100이 아니라 $20인가요"
        4일 실습에 드는 비용은 **$20을 넘지 않도록** 설계했습니다.
        $20에 알림을 걸어두면 **뭔가 잘못 돌아가고 있을 때 일찍 알 수 있습니다.**
        $100에 걸면 이미 다 쓴 뒤에 알게 됩니다.

5. **경고 조건**을 세 개 추가합니다.

    | % | 알림 유형 | 받는 사람 |
    |---|---|---|
    | 50 | 실제 비용 | 내 학교 이메일 |
    | 80 | 실제 비용 | 내 학교 이메일 |
    | 100 | 실제 비용 | 내 학교 이메일 |

6. **만들기**를 누릅니다.

!!! note "알림은 바로 오지 않습니다"
    예산 알림은 **조건을 넘었을 때만** 옵니다. 지금은 사용액이 0이라 메일이 오지 않는 게 정상입니다.
    "설정이 저장되었는지"만 확인하면 됩니다.

## 🔧 안 될 때

??? failure "학교 이메일을 넣었는데 “인증할 수 없습니다” 가 나옵니다"
    학교 도메인이 Microsoft의 학술 인증 목록에 없을 때 생깁니다.

    **순서대로 시도하세요.**

    1. 주소를 `@kunsan.ac.kr` 로 정확히 썼는지 확인 (오타·공백)
    2. 학교 웹메일에서 **인증 메일이 스팸함에 갔는지** 확인
    3. 그래도 안 되면 **강사를 부르세요.** 수업 중에 대체 경로를 안내합니다.

    !!! tip "강사용 대체 경로"
        GitHub Student Developer Pack 인증을 먼저 받은 뒤 그 자격으로 다시 시도하거나,
        학생증 이미지를 올려 수동 인증하는 경로가 있습니다. 승인까지 시간이 걸리므로
        **수업 중에는 강사 구독에 임시 계정을 받아 진행**하고, 개인 구독은 뒤에 연결합니다.

??? failure "카드 번호를 넣으라고 합니다"
    일반 **Azure 무료 계정** 가입 흐름으로 들어간 것입니다.

    1. 브라우저 탭을 닫습니다
    2. 주소에 `/free/students/` 가 들어간 링크로 **다시** 들어갑니다
    3. 이미 일반 무료 계정을 만들었다면 그대로 두고, 학생 구독을 **추가로** 만들면 됩니다

??? failure "“이미 계정이 있습니다” 라고 나옵니다"
    개인 Microsoft 계정으로 로그인한 상태일 수 있습니다.

    - 브라우저 **시크릿 창**을 열고 학교 이메일로 다시 진행하세요
    - Azure for Students는 **1인 1계정**입니다. 예전에 받은 적이 있다면 그 계정을 쓰세요

??? failure "비용 관리에 “예산” 메뉴가 안 보입니다"
    구독을 만든 직후에는 비용 데이터가 아직 없어 메뉴가 늦게 뜰 수 있습니다.

    1. 10분쯤 뒤에 다시 들어가 보세요
    2. 그래도 없으면 **Education Hub에서 크레딧 잔액을 직접 확인**하는 것으로 대체합니다.
       예산 알림은 쉬는 시간에 다시 시도하면 됩니다. **Lab 01은 그대로 진행하세요.**

??? failure "포털이 영어로 나옵니다"
    오른쪽 위 **⚙️(설정) → 언어 및 지역 → 한국어** 로 바꿀 수 있습니다.
    다만 이 가이드의 메뉴 이름은 한국어 기준이니, 영어로 쓰실 거면 괄호 안 영어 이름을 참고하세요.

## 💡 알아두면 좋은 것

**크레딧을 다 쓰면 자동으로 돈이 빠져나가나요?**

아닙니다. Azure for Students는 **카드가 등록되어 있지 않습니다.**
크레딧을 다 쓰면 Microsoft가 메일로 "종량제로 바꿀래?" 하고 묻고,
바꾸지 않으면 **구독과 리소스가 비활성화**됩니다. 요금이 청구되지 않습니다.

그래도 리소스를 켜둔 채 방치하면 크레딧이 줄어듭니다.
**매일 마지막 실습 뒤에 정리하는 습관**을 들이세요. 4일차 Lab 16에서 전체를 정리합니다.

**크레딧 말고 공짜로 더 주는 것도 있나요?**

있습니다. Azure Speech는 **매월 50만 뉴럴 문자**가 무료입니다.
3일차 Lab 11(음성 합성)은 이 무료 한도 안에서 끝납니다.
