## 1. 모델 하나 배포하기 (5분)

코드로 부르려면 **부를 대상**이 있어야 합니다. 지금은 가장 작은 모델 하나만 올립니다.

1. [ai.azure.com](https://ai.azure.com) → 내 프로젝트 → **모델 카탈로그**

2. `gpt-4o-mini` 를 검색해서 선택합니다.

3. **배포(Deploy)** 를 누릅니다.

4. **배포 유형을 `Global Standard` 로 선택합니다.**

    !!! warning "⚠ `Standard` 가 아니라 `Global Standard` 입니다"
        둘은 처리 위치와 **할당량 규모**가 다릅니다.
        이 구독에서 `Global Standard` 는 지역형 `Standard` 보다 **10배 넉넉**합니다.
        32명이 나눠 쓰려면 `Global Standard` 를 써야 합니다. 이유는 내일 Lab 03 에서 다룹니다.

5. 배포 이름을 확인합니다. 기본값 `gpt-4o-mini` 를 **그대로 쓰세요.**

6. **분당 토큰 수(TPM)를 `10K` 로 낮춥니다.**

    !!! warning "기본값 그대로 두면 뒷사람이 배포를 못 합니다"
        TPM 은 **구독 전체에서 나눠 쓰는 자원**입니다.
        앞 몇 명이 큰 값을 잡으면 나머지가 "할당량 부족" 으로 막힙니다.

        실습에 필요한 건 1인당 **2K 도 안 됩니다.** `10K` 면 충분히 여유롭습니다.
        (강사가 다른 값을 안내하면 그 값을 쓰세요)

7. **배포** → 완료될 때까지 기다립니다 (1~2분).

!!! warning "배포 이름을 꼭 메모하세요"
    코드에서 쓰는 건 **모델 이름이 아니라 배포 이름**입니다.
    기본값을 바꾸지 않았다면 `gpt-4o-mini` 입니다. **오타 하나로 404가 납니다.**

!!! question "왜 작은 모델인가요"
    지금은 "연결이 되는가"만 확인하면 되기 때문입니다. 작고 싸고 빠릅니다.
    **어떤 모델을 왜 고르는지, 배포 유형·TPM·컨텐츠 필터는 무엇인지**는
    내일(2일차) Lab 03에서 제대로 다룹니다.

## 2. 엔드포인트와 키 복사 (5분)

1. 프로젝트 홈 화면에서 **개요** 를 봅니다.

2. 두 가지를 복사해서 메모장에 붙여 둡니다.

    | | 무엇 | 생김새 |
    |---|---|---|
    | **엔드포인트** | 모델을 부르는 **주소** | `https://....openai.azure.com/...` |

!!! danger "키는 비밀번호입니다"

    - GitHub에 올리지 마세요

!!! question "키가 왜 두 개(Key 1, Key 2)인가요"
    서비스를 멈추지 않고 키를 교체하기 위해서입니다.
    Key 1을 쓰는 중에 Key 2를 새로 발급해 바꿔 끼우는 식입니다. **아무거나 하나 쓰면 됩니다.**

## 3. Python 환경 만들기 (12분)

작업할 폴더를 하나 만들고, 그 안에 **가상 환경**을 만듭니다.

=== "Windows"

    ```powershell
    mkdir ai901
    cd ai901
    python -m venv .venv
    .venv\Scripts\activate
    ```

=== "macOS · Linux"

    ```bash
    mkdir ai901
    cd ai901
    python -m venv .venv
    source .venv/bin/activate
    ```

**터미널 프롬프트 앞에 `(.venv)` 가 붙으면** 활성화된 것입니다.

```text

```

이제 패키지를 설치합니다.

```bash
pip install openai python-dotenv
```

설치 확인:

```bash

```

목록에 **`openai`** 와 **`python-dotenv`** 가 보이면 됩니다.

## 4. `.env` 파일 만들기 (8분)

`ai901` 폴더 안에 **`.env`** 라는 이름의 파일을 만듭니다. (확장자 없이 점으로 시작합니다)

```ini
AZURE_OPENAI_ENDPOINT=여기에_엔드포인트_붙여넣기
API_KEY=여기에_키_붙여넣기
MODEL_DEPLOYMENT_NAME=gpt-4o-mini
```

!!! warning "자주 틀리는 세 가지"
    - **따옴표를 넣지 마세요.** `API_KEY="abc"` ❌ → `API_KEY=abc` ✅
    - **등호 앞뒤에 공백을 넣지 마세요.** `API_KEY = abc` ❌
    - **줄 끝 공백**도 오류가 됩니다. 붙여넣고 끝에 커서를 둬서 확인하세요

!!! tip "VS Code에서 파일 이름이 `.env.txt` 로 저장될 때"
    저장할 때 파일 형식을 **모든 파일(All Files)** 로 바꾸고 `.env` 로 저장하세요.
    탐색기에서 **파일 확장명 표시**를 켜두면 확인하기 쉽습니다.

## 5. `verify.py` 실행하기 (15분)

같은 폴더에 **`verify.py`** 를 만들고 아래를 넣습니다.

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI(
    base_url=os.getenv("AZURE_OPENAI_ENDPOINT"),
    api_key=os.getenv("API_KEY"))

r = client.responses.create(
    model=os.getenv("MODEL_DEPLOYMENT_NAME"),
    input="안녕하세요. 한 문장으로 인사해 주세요.")
print(r.output_text)
```

실행합니다.

```bash
python verify.py
```

### 코드가 하는 일

| 줄 | 하는 일 |
|---|---|
| `load_dotenv()` | `.env` 를 읽어 환경 변수로 올립니다 |
| `client = OpenAI(...)` | **연결을 만드는 줄** — 아직 아무것도 보내지 않습니다 |
| `client.responses.create(...)` | **실제로 요청을 보내는 줄** |
| `print(r.output_text)` | 모델의 답을 출력합니다 |

!!! note "★ 이 구분이 시험에 나옵니다"
    **"이 코드에서 프롬프트를 제출하는 줄은?"** 이라는 문제가 실제로 출제됩니다.
    답은 `client.responses.create(...)` 입니다. `OpenAI(...)` 는 연결만 만듭니다.

## 🔧 안 될 때

!!! tip "오류 메시지의 숫자를 먼저 보세요"
    `401` · `404` · `429` 중 어느 것인지에 따라 원인이 완전히 다릅니다.

??? failure "401 Unauthorized — 인증 실패"
    **키가 잘못 전달된 것입니다.**

    1. `.env` 의 `API_KEY` 값 앞뒤에 **공백이나 따옴표**가 없는지 확인
    2. 포털에서 키를 **다시 복사**해서 붙여넣기
    3. Key 1 대신 Key 2로 바꿔 시도

??? failure "404 Not Found — 모델 배포를 못 찾음"
    **가장 흔한 오류입니다.** 배포 이름이 틀린 것입니다.

    1. Foundry 포털 → **배포** 목록에서 이름을 **그대로 복사**
    2. `.env` 의 `MODEL_DEPLOYMENT_NAME` 과 **글자 하나까지** 같은지 확인
    3. 모델 이름(`gpt-4o-mini`)이 아니라 **배포 이름**을 넣었는지 확인

    !!! note "헷갈리기 쉬운 지점"
        배포할 때 이름을 바꿨다면 그 이름을 써야 합니다.
        기본값 그대로 뒀다면 모델 이름과 배포 이름이 같아서 구분이 안 됩니다.

??? failure "429 Too Many Requests — 속도 제한"
    같은 교실에서 동시에 요청이 몰렸을 수 있습니다.

    1. **30초 뒤 다시 실행**
    2. 계속 나면 포털에서 배포의 **TPM(분당 토큰)** 할당량을 올립니다
    3. TPM은 내일 Lab 03에서 제대로 다룹니다

??? failure "ModuleNotFoundError: No module named 'openai'"
    **가상 환경이 꺼져 있습니다.**

    1. 터미널 프롬프트 앞에 `(.venv)` 가 있는지 확인
    2. 없으면 3번 단계의 활성화 명령을 다시 실행
    3. 그다음 `pip install openai python-dotenv` 재실행

    !!! tip "터미널을 새로 열면 가상 환경이 꺼집니다"
        매번 활성화해 줘야 합니다. 4일 내내 이 오류가 제일 많이 납니다.

??? failure "엔드포인트나 키가 None 이라고 나옵니다"
    **`.env` 를 못 읽고 있습니다.**

    1. `.env` 가 `verify.py` 와 **같은 폴더**에 있는지 확인
    2. 파일 이름이 `.env.txt` 로 저장되지 않았는지 확인
    3. 터미널의 현재 위치가 그 폴더인지 확인 (`cd ai901`)
    4. `load_dotenv()` 가 `os.getenv()` **보다 위에** 있는지 확인

??? failure "모델을 사용할 수 없다고 나옵니다"
    해당 리전에 그 모델이 없는 경우입니다.

    - Lab 01에서 **강사가 지정한 리전**으로 만들었는지 확인하세요
    - 다른 리전으로 만들었다면 리소스를 다시 만들어야 할 수 있습니다. 손을 드세요

??? failure "python 명령을 찾을 수 없습니다"
    === "Windows"
        `py -m venv .venv` 또는 `python3` 로 시도하세요.
    === "macOS"
        `python3 -m venv .venv` 로 시도하세요.
